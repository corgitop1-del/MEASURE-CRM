# STRUCTURA MEASURE

Застосунок для обмірів і розкладки підлоги. Кожна дошка/плитка — окремий об'єкт (id, ряд, координати, заготовка, статус), з яких рахується калькуляція.

## Запуск
```bash
npm install
npm run dev        # http://localhost:3000
npm run test       # Vitest
npm run typecheck
```

## Етап 1 (готово)
- `src/lib/layout/engine.ts` — розкладка планок (замок G/T, зсув стиків, ширина різу, повторне використання залишків) і плитки.
- Калькуляція: цілі/підрізані/із залишків, відходи, пачки, вартість.
- `src/app/page.tsx` — інтерфейс із кліком по елементу.
